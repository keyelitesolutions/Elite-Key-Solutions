Integritetspolicy

Elite Key Solutions behandlar personuppgifter för att kunna svara på förfrågningar och hantera bokningar.

Vilka uppgifter kan vi få?

Namn, telefonnummer, e-postadress samt information om bil, önskad tid, mötesplats och meddelande som du själv skickar via bokningsformuläret.

Varför behandlar vi uppgifterna?

Uppgifterna används för att kontakta dig, bedöma din förfrågan och planera eller bekräfta en bokning.

Hur skickas bokningen?

När du skickar formuläret skickas uppgifterna via formulärtjänsten FormSubmit till Elite Key Solutions e-postadress. FormSubmit används som teknisk tjänsteleverantör för att ta emot och vidarebefordra formulärmeddelandet. Webbplatsen använder inte längre din lokala e-postapp för att skicka bokningsförfrågan.

FormSubmit uppger att tjänsten behandlar formulärdata för att tillhandahålla formulärtjänsten. Läs aktuell information hos FormSubmit innan publicering och anpassa denna policy efter företagets faktiska rutiner.

Hur länge sparas uppgifterna?

Vi sparar endast uppgifter så länge de behövs för kontakt, bokning och eventuell uppföljning, eller så länge annan lag kräver det.

Dina rättigheter

Du kan begära information om vilka personuppgifter vi behandlar och, när det är tillämpligt enligt GDPR, begära rättelse eller radering.
