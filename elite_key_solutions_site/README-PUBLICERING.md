# Elite Key Solutions – publicering och Google

## 1. GitHub Pages
1. Skapa ett GitHub-konto på https://github.com/
2. Skapa ett **Public** repository, t.ex. `elite-key-solutions`.
3. Ladda upp innehållet i denna mapp så att `index.html` ligger i repositoryts rot.
4. Gå till **Settings → Pages**.
5. Välj **Deploy from a branch**, branch `main`, folder `/ (root)` och spara.
6. Din gratis adress blir ungefär `https://DITT-GITHUB-NAMN.github.io/elite-key-solutions/`.

## 2. Ändra de två platshållarna
Innan Google-registreringen: byt `YOUR-GITHUB-USERNAME` till ditt riktiga GitHub-användarnamn i `robots.txt`, `sitemap.xml` och JSON-LD i `index.html`.

## 3. Google Search Console
1. Öppna https://search.google.com/search-console/
2. Lägg till webbplatsen som **URL-prefix** med exakt GitHub Pages-adressen.
3. Verifiera ägarskapet enligt Googles instruktioner.
4. Öppna **Sitemaps** och skicka `sitemap.xml`.
5. Använd **URL Inspection** och begär indexering av startsidan.

## 4. Google Företagsprofil
Gå till https://business.google.com/ och lägg till/kräv Elite Key Solutions. Fyll i namn, kategori, telefon, webbplats, serviceområde och öppettider. Google bestämmer vilken verifieringsmetod som erbjuds.

## 5. Viktigt före publicering
- Kontrollera att telefonnummer, adress och e-post är korrekta.
- E-postadressen i den nuvarande sidan är `keyelitesoultions@gmail.com` (stavningen **soultions** bör kontrolleras).
- Bokningsformuläret skickar nu bokningsförfrågningar via FormSubmit utan att öppna kundens e-postapp. Första gången formuläret används måste mottagaradressen aktiveras via FormSubmit.
- Integritetspolicy och bokningsvillkor är grundutkast och bör anpassas efter företagets faktiska rutiner.
- Lägg inte in Google Analytics eller andra cookies utan att först bestämma hur samtycke och integritet ska hanteras.
